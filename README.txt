# Mentalidade de Elite — página de vendas

## Publicar grátis com GitHub Pages

1. Entre em https://github.com e faça login (com ajuda de um responsável, se necessário).
2. Crie um repositório público chamado `mentalidade-de-elite`.
3. Envie o arquivo `index.html` deste pacote para a raiz do repositório.
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
7. Aguarde a publicação. O endereço normalmente será:
   `https://SEU-USUARIO.github.io/mentalidade-de-elite/`

## Ativar o botão de compra

No `index.html`, procure por:

`<!-- TROQUE O # PELO LINK REAL DO CHECKOUT ANTES DE PUBLICAR -->`

Substitua o `href="#"` do botão `QUERO MEU E-BOOK` pelo link real de checkout fornecido pela plataforma de pagamento.

Não publique o botão como se o pagamento já estivesse ativo. Configure recebimento e conta de vendas com a participação de um responsável e respeite as regras/idade mínima da plataforma.

## Personalização

O site usa uma paleta preto, vinho e vermelho e adapta-se a telas de celular.
